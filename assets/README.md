# Exported Assets

Generated Blender deliverables are organized into:

- `generated/`: editable `.blend` sources, Roblox-ready `.glb` exports, and the
  machine-readable validation report.
- `previews/`: color-managed PNG renders for visual review.

The Blender preview stage is not included in the GLBs. Regenerate these files
from the scripts in `blender/` rather than editing exported meshes directly.

# Tree of Life Roblox

Development repository for Tree of Life V0.5, including the Africa Savanna Village region.

## Project goals
- Preserve the existing Roblox Studio game and its completed levels.
- Create polished, stylized 3D assets in Blender.
- Import optimized models into Roblox Studio.
- Add exploration, gathering, mining, crafting, quests, and XP.

## Workflow
This repository will hold Blender modeling scripts, Roblox Luau source, asset export tooling, and documentation. The existing Roblox Studio place remains the source of truth until it is backed up and integrated safely.

## Safety
Do not overwrite or replace the existing Roblox place. Back up the `.rbxl` or `.rbxlx` file before syncing any project files.
